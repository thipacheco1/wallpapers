# Wallpapers para Lively Wallpaper

Wallpapers animados prontos para instalar no [Lively Wallpaper](https://github.com/rocksdanister/lively).

## Downloads

- [INKBOUND — Batalha Infinita](./INKBOUND-Lively-v1.0.0.zip)
- [ÚLTIMA ZONA — Ecossistema Zumbi v1.0.1](./ULTIMA-ZONA-Lively-v1.0.1.zip)

## Como instalar

1. Baixe o arquivo ZIP do wallpaper desejado.
2. Abra o Lively Wallpaper.
3. Arraste o ZIP para a janela do Lively ou use **Adicionar wallpaper**.
4. Selecione o wallpaper na biblioteca.

Os pacotes publicados contêm o código de execução minificado e ofuscado, as capas e os metadados necessários para o Lively.
